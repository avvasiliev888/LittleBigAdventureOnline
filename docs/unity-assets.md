# Ассеты Unity — что проверено на практике

Читать перед любой работой с ассетами: коммит ассетов, обновление `.meta`,
подключение клипов, разбор зависимостей. Всё ниже проверено на этом проекте,
а не является общим советом.

Цифры вручную не собирать — есть `tools/unity/asset-map.py`:

```powershell
python tools/unity/asset-map.py                 # сводка по ядровым ассетам
python tools/unity/asset-map.py --deps Warrior  # замыкание зависимостей по GUID
python tools/unity/asset-map.py --untracked     # что не в git и почему
python tools/unity/asset-map.py --lfs           # бинарник вне LFS
```

## 1. Git LFS обязателен для бинарников

`.gitattributes` отправляет в LFS: `*.fbx`, `*.png`, `*.tga`, `*.wav`, `*.obj`,
`*.blend`, `*.zip`, `*.ttf` и ещё ряд форматов. Правило оператора:
**бинарник больше 100 КБ — в LFS**.

Проверка, что файл реально ушёл указателем, а не байтами:

```powershell
git show ":путь/к/файлу.fbx" | Select-Object -First 1   # version https://git-lfs...
git cat-file -s ":путь/к/файлу.fbx"                      # ~131 байт, не мегабайты
```

Три клипа лука (`Standing Aim Idle 01`, `Standing Aim Recoil`, `Standing Idle 01`,
всего **1,47 МБ**) занимают в истории **131 байт** каждый.

## 2. Unity молча теряет ссылки — резолвит в `null` без ошибки

Главная мина проекта, стоившая часов. Анимационное состояние ссылается на клип
тройкой `{fileID, guid, type}`, где `fileID` — это `internalID` клипа из `.meta`.

Два разных случая:

| `fileID` | Что означает | Работает? |
|---|---|---|
| `7400000` | «первый клип в файле», резолвится позиционно | да, даже без `internalID` |
| `1827226128182048838` | конкретный внутренний ID клипа | **только если поле есть в `.meta`** |

**Ошибка не появляется нигде.** Состояние просто ничего не анимирует; признак
виден лишь по `[diag]`-логу: bind pose `head=0,535 anchorY=0,793
hipsRot=0,0,0,0,0,0` и `changes=1` у всех состояний.

Бывшая тревога по этому поводу **закрыта замером 19.11.2026**
(`docs/warrior-animation-ledger.md` § 9): после потери `internalID` в шести
`BaseMale*.fbx.meta` все клипы разрешились — `isHuman=True empty=False`.
Позиционное `7400000` работает и без таблицы. Не перепроверять.

## 3. `.meta` обязателен у каждого файла в `Assets`, включая скрипты

Unity генерирует `*.cs.meta` с `guid`. Если меты нет, Unity создаст новую при
следующем импорте — GUID изменится, и ссылки из префабов и контроллеров
разъедутся. Поэтому новый `.cs` коммитить **вместе с** `.meta`.

Формат: `fileFormatVersion: 2` и `guid`. Детерминированная генерация и проверка
коллизий по всем метам каталога — в `tools/unity/asset-map.py` и в истории
коммита `0e5caab`.

## 4. Каталог `AllStarCharacterLibrary` — сторонний пакет, 249 файлов не в git

Внутри перемешано нужное и мусор. Осознанно **не** отслеживается (`196` файлов):

- `Models/Materials/Marketing/` — рекламные материалы пака (`GroupShot.png`,
  `B&BIcon.png`, `SexySidekicks.mat`, `newAds.prefab`);
- `Models/Characters/` — модели `A03`, `Ninjas` (не используются);
- `Models/RootAnimsFemale/` — женские анимации (персонаж один, мужской);
- `Models/StatusBars/`, `Models/CollisionHelpers/` — чужие префабы полосок
  здоровья и хелперов коллизий;
- `Models/Materials/` — чужие материалы;
- `Assets/_Recovery/` — автоматическое восстановление Unity.

Отслеживаются только клипы, на которые реально ссылается наш контроллер:
`BaseMale@1HIdle`, `@1HAttack`, `@1HWalkF`, `@1HCombatRunF`, `@1HPain`,
`@1HDeathA` и три клипа лука.

заголовки не распознаются как заголовки. `docs/archery-bow-worklog.md` и
