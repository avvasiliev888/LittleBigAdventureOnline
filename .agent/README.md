# .agent/ — служебная папка конвейера «Тандем»

Здесь лежит всё, что нужно машине состояний конвейера, а не человеку-читателю.
Читать её на каждом шаге не нужно: агент заглядывает только в те файлы, которые
нужны текущему действию.

## Файлы

| Файл | Кто пишет | Кто читает | Коммитится |
|---|---|---|---|
| `config.json` | пользователь/установщик, редко | `orchestrator`, `gates.ps1`, агент перед платным вызовом | да |
| `spend.jsonl` | агент, по строке на платный вызов | агент перед каждым платным вызовом | да |
| `telegram.json` | пользователь один раз | `notify.ps1` | **нет** (секрет) |
| `away` | агент по фразе «Я уезжаю» / «Я вернулся» | `notify.ps1`, агент | **нет** (локальный флаг) |
| `protocol.md` | человек | агент в начале сессии с конвейером | да |

## `spend.jsonl` — формат строки

Одна строка = один платный вызов, JSON объект:

```json
{"ts":"2026-11-22T14:05:00+03:00","task":"T-012","role":"executor","model":"ois-gemma-4-26B","in":18400,"out":2100,"cache_in":0,"usd":0.0067}
```

Поля: `ts` (ISO 8601 с зоной), `task` (id задачи или `setup`), `role`
(`architect|executor|reviewer|debugger|gate`), `model`, `in`/`out`/`cache_in` (токены),
`usd` (оценка по ценам из `config.json`), `estimated` (true — если токены не измерены,
а числа поставлены агентом на глаз).

**Учёт оценочный по деньгам.** Точное число токенов агенты не получают, поэтому
в `usd` — оценка, а настоящий предохранитель — счётчик **вызовов**
(`monthly_cap_calls`): конвейер считает каждый платный вызов и передаёт журнал
архитектору, тот пишет по строке на вызов. Замер 22.11.2026: конвейер насчитал
4 вызова, а в журнал попало 2 — отсюда поле `estimated` и журнал в промпте отчёта.

## `away` — флаг отсутствия пользователя

- Нет файла — пользователь за компьютером, Telegram молчит.
- Есть файл — агент шлёт пинги через `notify.ps1` на важных вехах и при блокерах.
- Файл в `.gitignore`: состояние машины, а не репозитория.

## Что сюда НЕ кладём

Отчёты по задачам (`docs/reports/`), логи гейтов (`docs/reports/logs/`),
планы (`docs/plan_for_gemma.md`) — это артефакты для человека.
