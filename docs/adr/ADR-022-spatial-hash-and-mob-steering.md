# ADR-022. Spatial hash для статики и steering мобов

**Статус:** принят
**Дата:** 2026-11-11
**Связано:** ADR-001, ADR-019, ADR-021, `docs/PLAN.md` §6.9

## Контекст

ADR-021 ввёл серверные коллизии на 584 статических кругах. `MovementCollision` перебирал
весь массив на каждом шаге, а `Depenetrate` — ещё раз на каждом проходе. При 20 игроках и
мобах это оставалось в бюджете тика, но линейный рост не позволял расширять мир: следующая
зона или плотный лес стоили бы O(N) на каждое движение.

Мобы при этом двигались строго к цели. Если камень оказывался ровно на линии, моб упирался
в него, скольжение давало нулевую касательную и AI мог стоять у препятствия бесконечно.
Полноценный A* для трёх типов мобов и разреженных круглых препятствий был бы избыточен:
нужен дешёвый локальный обход, а не маршрут через всю карту.

## Решение

### 1. Равномерная сетка внутри `WorldColliders`

- Ячейка **8 м**; границы сетки = AABB центров препятствий плюс `MaxRadius`.
- Каждый коллайдер лежит ровно в одной ячейке; внутри ячейки сохраняется порядок исходного
  массива, ячейки обходятся по строкам и столбцам. Результат запроса детерминирован.
- Сетка строится один раз в конструкторе `WorldColliders`; сам набор неизменяемый.
- `Query(x, z, radius)` возвращает круги, `QueryArea(minX, minZ, maxX, maxZ)` — прямоугольник.
  Оба метода фильтруют точные границы, а не только ячейки, поэтому не отдают лишние углы.
- `MovementCollision` один раз выбирает кандидатов на весь шаг (AABB отрезка + радиус актора +
  `MaxRadius`) и переиспользует их во всех проходах скольжения. `Depenetrate` делает точечный
  запрос. Линейных проходов по `world.Items` в движении больше нет.
- `MovementCollision.TryGetFirstObstacleHit` — публичный запрос первого касания на отрезке;
  им пользуется steering и тесты.

### 2. Steering вместо A*

`MobSteering.Resolve` смотрит вперёд на `max(2.2 м, 3 × радиус)` (не дальше цели). Если на
луче есть препятствие:

1. берётся нормаль в точке касания и две касательные;
2. сторона обхода выбирается по большей проекции на желаемое направление;
3. при точной симметрии сторона выбирается по чётности `entityId` — без случайности;
4. выбранная сторона хранится в `EntityState.AiAvoidSide`, пока препятствие на луче,
   чтобы моб не дёргался между левой и правой касательной;
5. к касательной добавляется 20% прямого направления, чтобы моб не уходил строго
   перпендикулярно, а обходил препятствие по дуге.

Сторона сбрасывается, когда луч свободен или моб дошёл до цели. Это локальный обход,
а не поиск пути: вогнутые ловушки из нескольких препятствий он не решает, зато не требует
навмеша, сетки проходимости и не добавляет аллокаций в тик.

## Альтернативы

| Вариант | Почему отклонён |
|---|---|
| Оставить линейный перебор | 584 объекта на шаг и на каждый проход скольжения; не масштабируется на новые зоны |
| Сетка проходимости + A* | Нужны экспорт, сглаживание пути и пересчёт при движущихся акторах; избыточно для разреженных кругов |
| NavMesh Unity | `Simulation.Core` обязан быть без Unity (ADR-001), сервер headless |
| Случайный выбор стороны при симметрии | Недетерминированный replay и рассинхрон тестов |
| Обход только по касательной без forward bias | Моб может бесконечно кружить вокруг камня, не приближаясь к цели |

## Последствия

- Стоимость запроса зависит от плотности мира, а не от общего числа препятствий. Размер
  ячейки 8 м выбран под радиусы деревьев/камней (≤ 1.6 м) и скорость акторов; при появлении
  препятствий больше 8 м их всё равно находит `MaxRadius`, но кандидатов станет больше.
- Результаты запросов и порядок кандидатов детерминированы, поэтому серверный replay,
  тесты и клиентское предсказание остаются согласованными.
- `WorldColliders` должен строиться из того же JSON и в том же порядке на сервере и клиенте;
  это уже гарантирует общий хеш конфигов (ADR-011).
- Steering не гарантирует выход из U-образной ловушки. Если такие места появятся в сцене,
  следующим шагом будет локальная сетка проходимости или waypoint-граф, а не усложнение
  текущего кода.
- У мобов появилось серверное поле `AiAvoidSide`; в снапшот оно не входит и на клиент не
  передаётся.
