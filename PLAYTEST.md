# PLAYTEST — запуск Albion Online Prototype 0.8.2

> **Статус графики:** в **0.8.2** уже включён CC0-набор **KayKit**: Knight, три скелета-
> моба, пять видов оружия и props окружения. Это stylized low-poly, а не финальный
> Albion-level арт; Synty/Mixamo остаются опцией для следующей итерации.

Эта инструкция — для проверки собранной версии **0.8.2** на своём компьютере, в локальной
сети и через интернет. Версия всегда написана в правом нижнем углу экрана игры:
`LittleBigAdventureOnline v0.8.2`. Если там `0.7.1` или `0.7.0` — запущена старая сборка,
её нужно заменить новой.

## 1. Что распаковать

Релизные файлы лежат в `artifacts/release/`:

| Файл | Что внутри |
|---|---|
| `AlbionPrototype-desktop-0.8.2-win-x64.zip` | Windows-клиент с KayKit; распаковать целиком |
| `AlbionPrototype-server-0.8.2-win-x64.zip` | сервер + `config/`; распаковать целиком |
| `AlbionPrototype-0.8.2.apk` | Android-клиент с KayKit (ARM64, Android 8.0+) |
| `server/` | уже распакованный сервер (для запуска с диска) |
| `SHA256SUMS.txt` | контрольные суммы всех файлов |

Не запускайте `.exe` из ZIP-архива: Windows распакует только его, а рядом не будет
`AlbionPrototype_Data` (клиент) или `config` (сервер). Сначала полностью распакуйте архив.

### Что нового в 0.8.2

- Игрок — **KayKit Knight** с 75 анимациями, URP Lit-текстурами и оружием в правой руке.
- Мобы — три **KayKit Skeleton** (Minion / Rogue / Warrior) вместо старых примитивов.
- Пять видов оружия: меч, топор, **лук**, **посох**, кинжал. Переключение — клавиши `1`–`4`; у каждого оружия свой набор атакующих клипов.
- Восемь props окружения KayKit (бочка, ящики, сундук, факел, стол, стул, колонна, флаг).
- Версия в углу — `v0.8.2`, Android versionCode **8**.
- Исправлена анимация: слой Animator имеет вес 1, состояния называются авторскими
  клипами (`Walking_A`, `Running_A`, `1H_Melee_Attack_Chop`), мобы тоже анимируются.
- Из модели Knight удалены 7 запечённых мечей/щитов; активен ровно один слот оружия.
- Атаки игрока — комбо из авторских клипов KayKit: рубящий, диагональный, горизонтальный, укол; для лука — `1H_Ranged_Shoot`, для посоха — `Spellcast_Shoot/Long`.
- Клипы `Idle/Walking_A/Running_A` зациклены на уровне importer: ноги больше не замирают после первого шага.
- Моб, нанёсший урон, проигрывает `1H_Melee_Attack_Chop`; раньше у мобов был только `Hit_A`.
- Добавлен настоящий 30-секундный PlayMode-бот (`Assets/Editor/BotPlaytest.cs`):
  бег → удар → труп → лут, с проверкой `Animator` и тремя скриншотами в
  `artifacts/playtest/`.

## 2. Быстрый запуск на одном ПК

1. Распакуйте сервер, откройте терминал в его папке и запустите:

   ```powershell
   .\Server.exe --udp 9050
   ```

   В консоли должны появиться строка `config: ...` и `UDP-сервер слушает порт 9050`.
   Оставьте терминал открытым: это и есть мир.

2. Распакуйте Windows-клиент и запустите `AlbionPrototype.exe`. Без аргументов он
   подключается к `127.0.0.1:9050`.

3. Проверьте правый нижний угол: `v0.8.2`. Если версия старая, скачайте APK/архив заново.

При первом запуске Windows Firewall может спросить разрешение для `Server.exe` —
разрешите **частные сети** (для LAN) и, если нужен интернет, **общественные**.

## 3. LAN: телефон или второй компьютер

### 3.1. Узнать IP сервера

На компьютере с сервером:

```powershell
ipconfig
```

Нужен `IPv4-адрес` активного Wi-Fi/Ethernet, например `192.168.1.50`. Телефон и компьютер
должны быть в одной Wi-Fi-сети (не в «гостевой» сети с изоляцией клиентов).

### 3.2. Разрешить порт

Сервер слушает **UDP 9050**. Разрешите входящие UDP 9050 в брандмауэре Windows
(от имени администратора):

```powershell
New-NetFirewallRule -DisplayName "Albion UDP 9050" -Direction Inbound `
  -Protocol UDP -LocalPort 9050 -Action Allow -Profile Private,Domain
```

Если меняли порт — замените `9050` и в правиле, и в командах ниже.

### 3.3. Подключить Windows-клиент

```powershell
.\AlbionPrototype.exe -serverHost 192.168.1.50 -serverPort 9050
```

Или задайте переменные окружения перед запуском:

```powershell
$env:ALBION_SERVER_HOST = "192.168.1.50"
$env:ALBION_SERVER_PORT = "9050"
.\AlbionPrototype.exe
```

### 3.4. Подключить Android

1. Установите `AlbionPrototype-0.8.2.apk` (разрешите установку из неизвестных источников).
2. На стартовом экране введите IP `192.168.1.50` и порт `9050`.
3. Если APK собирался скриптом `build-android.ps1`, IP компьютера уже подставлен в
   `Resources/MobileServerHost.txt`; всё равно проверьте его на стартовом экране.

## 4. Через интернет

Самый простой вариант — проброс порта на роутере:

1. В настройках роутера сделайте **port forwarding**: внешний UDP `9050` →
   внутренний IP сервера (`192.168.1.50`), UDP `9050`.
2. Узнайте внешний IP (например, на сайте провайдера или `curl ifconfig.me`).
3. Запустите сервер и клиент:

   ```powershell
   .\AlbionPrototype.exe -serverHost <ВНЕШНИЙ_IP> -serverPort 9050
   ```

4. Разрешите UDP 9050 в Windows Firewall для профиля, который используется
   (обычно `Public` для прямого подключения).

Ограничения:

- Если провайдер использует **CGNAT** (серый IP), проброс не сработает. Тогда используйте
  VPN-сеть с виртуальным IP: **ZeroTier**, **Tailscale** или **Radmin VPN**. Установите
  клиент на сервер и на игровое устройство, возьмите виртуальный IP сервера и укажите его
  в `-serverHost`.
- Не открывайте порт наружу без необходимости: у прототипа нет паролей и шифрования,
  а конфиги и команды проверяются, но это всё ещё тестовый сервер.
- Для игры вдвоём на одном ПК можно запустить два клиента с одним `-serverHost`
  и разными окнами.

## 5. Управление

| Действие | Клавиша/кнопка |
|---|---|
| Ходьба | `WASD` |
| Бег к курсору | удерживать **ЛКМ** или **ПКМ** |
| Бежать в точку | один клик **ЛКМ/ПКМ** (появится сужающийся кружок) |
| Подобрать лут | клик **ЛКМ** по трупу (персонаж подбежит и подберёт) |
| Атака | `Space` (на телефоне — кнопка «УДАР») |
| Инвентарь | `I` |
| Сбор ресурса | `F` рядом с деревом/жилой (на телефоне — «Сбор») |
| Крафт / навыки | `C` / `K` |
| Торговец | подойти к NPC, панель откроется сама |

Инвентарь (`I`) показывает надетое снаряжение, серебро/Славу и журнал добычи текущего
сеанса. Мир не сохраняется на диск: после перезапуска сервера инвентарь и трупы исчезают.

## 6. Сброс мира и перезапуск

Мир полностью **in-memory**:

1. Остановите сервер: `Ctrl+C` в его терминале (или закройте окно).
2. Запустите заново:

   ```powershell
   .\Server.exe --udp 9050
   ```

3. Клиент переподключится сам; если нет — закройте и запустите клиент снова.

При рестарте сбрасываются мобы, трупы, ресурсы, серебро/Слава и инвентарь. Конфиги
читаются из папки `config` рядом с `Server.exe`; чтобы проверить их отдельно:

```powershell
.\Server.exe --validate-config-only
```

Ожидаемый результат — `config OK` и хеш конфигов. Хеш клиента и сервера должен совпадать,
иначе клиент откажется подключаться (`config error`). В этом случае пересоберите клиент
или возьмите `config` из того же релиза.

## 7. Если что-то не работает

| Симптом | Что проверить |
|---|---|
| В углу `v0.7.0` или `v0.6.0` | запущена старая сборка; распакуйте архив 0.8.2 заново |
| `Address already in use` | порт занят; запустите `--udp 9051` и клиент с `-serverPort 9051` |
| Клиент не подключается по LAN | IP из `ipconfig`, одна Wi-Fi-сеть, UDP 9050 в Firewall |
| Подключается с телефона, но не с ПК | аргумент `-serverHost`/`-serverPort` или переменные окружения |
| Чёрный экран/нет арены | запускать `AlbionPrototype.exe` из распакованной папки целиком |
| Лаги/телепорты | проверьте Wi-Fi; для теста задержки/потерь: `--delay 100 --loss 30` |
| Хеш конфигов не совпал | используйте `config` из релизного server-архива и перезапустите клиент |

```powershell
Get-FileHash .\AlbionPrototype-server-0.8.2-win-x64.zip -Algorithm SHA256
```

Сравните с `SHA256SUMS.txt`. Хеши также продублированы в `artifacts/release/RELEASE.md`
и `docs/stage8-validation.md`.
